数据迁移工具

把旧数据从 file:// 搬到 http://localhost:8000

当前打开方式：

当前是 file:// 协议打开，数据在这里。
点下方按钮导出全部数据，然后切到 http://localhost:8000 打开本页面导入。
1
导出全部数据：点击按钮，会自动下载一个 JSON 文件。
2
打开本地服务器版：双击「启动本地服务器.bat」，然后浏览器地址栏访问 http://localhost:8000/数据迁移.html
当前是 http://localhost:8000，数据将导入到这里。
把上一步导出的 JSON 内容粘贴到下方框，点导入。
3
导入数据：粘贴导出的 JSON 内容，或上传 JSON 文件。
4
打开工作台：点击进入工作台，数据已迁移完成。
